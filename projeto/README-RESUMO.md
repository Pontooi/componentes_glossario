# 🎨 Tema 07 — Resumo do projeto

Site com 3 páginas sobre componentes de UI e design systems, inspirado no
`glossario_v3.html` e no `T7_glossario-design.html` do curso mob07.

> Versão completa: veja [`README.md`](./README.md).

## Páginas
- `html/index.html` — apresentação e menu
- `html/componentes.html` — biblioteca de componentes com demo ao vivo + código
- `html/glossario.html` — glossário de termos de Design Systems

## Pastas
```
html/   → as 3 páginas
css/    → style.css (estilo + tema escuro/claro)
js/     → theme.js, componentes.js, glossario.js
```

## Recursos
- Busca e filtro por categoria nas páginas de componentes e glossário
- Tema **escuro (padrão, tons de roxo)** com botão para alternar para o **tema claro**
- Botão "voltar ao topo"
- Sem frameworks — HTML, CSS e JS puros

## Como abrir
Duplo clique em `html/index.html`, ou publique a pasta no GitHub Pages.
